# SEO Content Opportunity Engine

An AI-powered SEO analysis tool that helps identify content opportunities from search-performance data.

The application processes SEO data, scores potential opportunities, classifies search intent, assigns priority, and uses Google's Gemini API to generate recommendations for what to do next.

## What it does

The tool takes SEO data as input and turns it into a prioritized opportunity report.

# SEO Content Opportunity Engine

A small Streamlit app that helps find content opportunities from SEO data.

**[Live Demo →]([[YOUR-WEBSITE-LINK](https://seo-ai-content-engine.streamlit.app/)](https://seo-ai-content-engine.streamlit.app/))**

The workflow is:

1. Upload SEO data
2. Validate and process the data
3. Calculate an opportunity score
4. Classify search intent
5. Assign priority and opportunity category
6. Generate recommended actions
7. Use Gemini to provide AI-based recommendations
8. Display the final opportunity report

The goal is to reduce the amount of manual analysis needed to identify which pages or keywords deserve attention first.

## Features

- CSV-based SEO data analysis
- Opportunity scoring
- Search intent classification
- Priority assignment
- Opportunity categorization
- Recommended actions
- Gemini API integration
- Interactive Streamlit interface
- Downloadable/structured analysis output

## Tech Stack
